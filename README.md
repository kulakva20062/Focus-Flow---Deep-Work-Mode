# Focus Flow - Deep Work Mode

Плагин для VS Code, который помогает сосредоточиться на коде, убирая все лишние элементы интерфейса.

## Автор плагина 

`Кулаковский Владислав Андреевич, группа: M3102`

## Функции

### 🔧 Три основные команды:

1. `Focus Flow: Сохранить стандартный layout`
   - Сохраняет текущее расположение панелей как стандартное

2. `Focus Flow: Войти в режим фокуса`
   - Скрывает все панели (боковая, нижняя, статус бар)
   - Переключает на высококонтрастную тему
   - Включает полноэкранный режим
   - Идеально для глубокой концентрации!

3. `Focus Flow: Вернуться в стандартный режим`
   - Восстанавливает сохраненный layout
   - Возвращает оригинальную тему
   - Выходит из полноэкранного режима

## Горячие клавиши

- `Ctrl+shift+1` Сохранить стандартный layout
- `Ctrl+shift+2` Войти в режим фокуса
- `Ctrl+shift+3` Вернуться в стандартный режим

## Использование

1. Сначала настройте VS Code так, как вам удобно
2. Выполните команду "Focus Flow: Сохранить стандартный layout"
3. Теперь вы можете быстро переключаться между режимами
